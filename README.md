# Знаходження елемента в однозв'язному списку

Цей репозиторій містить розв'язок тестового завдання.

## Опис завдання
Дано однозв'язний список, що містить `n` елементів. Потрібно знайти елемент, що знаходиться на позиції `[2n/3] - 1`, якщо `n > 1`, інакше повернути `null`.

## Підхід до розв'язання
Оскільки в однозв'язному списку неможливо заздалегідь дізнатися кількість елементів `n` без його повного обходу, алгоритм базується на двопрохідному підході:
1. **Перший прохід:** рахуємо загальну кількість елементів `n`.
2. **Перевірка:** якщо `n <= 1`, повертаємо `None` (аналог `null` у Python).
3. **Обчислення індексу:** за заданою формулою `(2 * n) // 3 - 1` визначаємо позицію потрібного елемента.
4. **Другий прохід:** проходимо список з початку до обчисленої позиції та повертаємо значення елемента.
